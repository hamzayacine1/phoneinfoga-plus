Truecaller, Eyecon, Twilio, Abstract, Numverify, Google CSE… tes clés restent dans ton navigateur (localStorage), elles ne sont jamais stockées sur le serveur.
Usage légal uniquement.
Analyse uniquement les numéros que tu es autorisé à vérifier. Les intégrations Truecaller/Eyecon utilisent des API non officielles (risque de blocage de compte).
Propulsé par PhoneInfoga v2.11.0 · interface étendue

⚙️ Clés API & tokens

Stockées uniquement dans ton navigateur. Un scanner sans clé n'est simplement pas exécuté.
⚡ Remplissage automatique
🔵 Token Truecaller par SMS (sans extraction manuelle)
Truecaller t'envoie un SMS avec un code → l'app crée le token automatiquement et le remplit. ⚠️ Numéro jetable conseillé (risque de ban).
📋 Coller des en-têtes capturés (remplit tout d'un coup)
Exporte/copie tes clés pour les transférer sur un autre appareil.
Depuis l'app Truecaller (Android) : sauvegarde → extraire le token authorization, ou capture réseau. Risque de bannissement de ton compte — utilise un compte jetable.
Depuis l'app Eyecon : capture réseau des en-têtes e-auth*.
twilio.com → Console → Lookup API (gratuit avec compte).
phonevalidation.abstractapi.com — 100 requêtes/mois gratuites.
numverify.com — 100 requêtes/mois gratuites.
Nouvelles sources (ajoutées)
numlookupapi.com — ~250 requêtes/mois gratuites (pays, opérateur, localisation).
veriphone.io — plan gratuit (validité, type de ligne, région, opérateur).
opencnam.com — nom de l'appelant (CNAM). Crédits d'essai gratuits.
ipqualityscore.com — 500 requêtes/mois gratuites (score de fraude, spam, opérateur).
omkar.cloud — 200 requêtes/mois gratuites (opérateur + type de ligne).
callerapi.com — UNE clé pour Truecaller + CallApp + ViewCaller + Eyecon + Hiya. Payant (crédits).
